Blend Space에서 메시만 앞으로 밀려 나가는 문제

2026.10.05 4분 분량

이동 방향 확인

캐릭터의 이동 애니메이션을 Blend Space로 구성하던 중, 애니메이션을 재생하면 캐릭터가 의도한 것보다 앞으로 밀려 나가는 현상이 발생했습니다.

WASD 입력에 따라 캐릭터가 앞, 뒤, 좌, 우로 자연스럽게 움직이도록 Blend Space를 구성하고 있었기 때문에 먼저 이동 방향을 계산하는 부분부터 확인했습니다.

현재 Anim Blueprint에서는 Movement Component에서 Velocity를 가져온 다음, 캐릭터의 현재 Actor Rotation과 함께 Calculate Direction에 전달하여 Direction 값을 계산하고 있습니다.

Velocity
   +
Actor Rotation
   ↓
Calculate Direction
   ↓
Direction

Calculate Direction은 캐릭터가 바라보고 있는 방향을 기준으로 실제 이동 방향을 각도로 계산합니다.

예를 들어 캐릭터가 정면을 바라보고 있을 때 정면으로 이동하면 Direction은 0에 가까운 값이 되고, 오른쪽으로 이동하면 약 +90도, 왼쪽으로 이동하면 약 -90도, 뒤로 이동하면 ±180도에 가까운 값이 됩니다.

먼저 Direction 계산에 문제가 있는지 확인했지만, 이 부분에서는 이상한 점을 찾지 못했습니다.

Root Bone 확인

다음으로 Skeleton의 Root Bone을 확인했습니다.

Skeleton Tree를 살펴보니 현재 스켈레톤은 다음과 같은 구조를 가지고 있었습니다.

root
└─ pelvis
   └─ spine_01
      └─ ...

최상위에 root 본이 존재했기 때문에 Root Bone 자체가 없는 문제는 아니었습니다.

show collision 명령으로 캡슐을 화면에 표시해 보니, 캡슐은 제자리에 있고 메시만 앞으로 밀려 나가고 있었습니다. 캐릭터의 실제 위치는 그대로인데 애니메이션만 앞서 나간다는 뜻이었습니다.

그렇다면 Blend Space에 사용하고 있는 애니메이션의 Root Bone이 실제로 이동하고 있는지 확인할 필요가 있었습니다.

애니메이션은 화면상으로 캐릭터가 제자리에서 움직이는 것처럼 보이더라도, 애니메이션 데이터의 Root Bone에 이동값이 포함되어 있을 수 있습니다. 이 경우 Root Motion 설정에 따라 그 이동값이 캐릭터를 실제로 움직이거나, 메시만 캡슐에서 벗어나 보이게 만들 수 있습니다.

Force Root Lock 적용

애니메이션 시퀀스 에셋의 Details 패널에서 Root Motion 항목을 열면 Force Root Lock 옵션이 있습니다. 이 옵션은 Root Motion 사용 여부와 상관없이 Root Bone을 원래 위치에 고정하기 때문에, Root Bone의 이동이 원인이라면 이 옵션을 켰을 때 현상이 사라질 것이라고 생각해 적용해 보았습니다.

Force Root Lock을 활성화한 이후 캐릭터가 앞으로 튀어나가던 현상이 사라졌습니다.

결과적으로 이번 문제는 Direction 계산이나 Root Bone의 부재 때문이 아니라, Blend Space에 사용된 애니메이션의 Root Bone에 앞으로 이동하는 값이 들어 있었기 때문이었습니다. Root Motion이 추출되지 않는 상태에서 이 이동값이 그대로 재생되면서, 캡슐은 제자리에 있는데 메시만 앞으로 밀려 나갔던 것입니다.

정리하면 캐릭터의 위치와 메시의 위치가 서로 다른 경로로 정해진다는 것이었습니다.

입력 → Character Movement → 캡슐 이동 (실제 위치)

Velocity → Calculate Direction → Blend Space → 애니메이션
                                                 ↓
                                     Root Bone 이동값 → 메시 위치

Root Motion이 추출되지 않으면 Root Bone의 이동값은 캡슐에 반영되지 않고 메시에만 적용되기 때문에, 캡슐과 메시가 서로 어긋나게 됩니다.

이번 문제를 해결하면서 캐릭터의 이동이 입력과 이동 계산뿐 아니라, 애니메이션 데이터 자체에도 영향을 받는다는 것을 알게 되었습니다.

앞으로 Blend Space를 구성할 때는 애니메이션의 포즈만 확인하는 것이 아니라 Root Bone의 이동과 Root Motion 관련 설정도 함께 확인해야겠습니다.
