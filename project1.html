Eternal Quest: Rebirth

게임 제목 Eternal Quest: Rebirth
게임 소개 언리얼 엔진과 게임플레이 어빌리티 시스템을 활용한 액션 롤플레잉 게임
진행 기간 2025.05.26 ~ 2025.06.26
개발 인원 프로그래머 1명
사용 기술 Unreal Engine, Gameplay Ability System, Gameplay Tag
담당 파트 게임플레이 어빌리티 시스템 기반 전투 구현
게임 UI 및 인터랙션 시스템 구현
픽업 아이템 투척
캐릭터 정면 기준 ±45도 랜덤 방향과 이동 거리를 적용하여 매번 다른 방향으로 튕겨 나가도록 구현
LineTrace로 목표 지점 높이를 실시간 계산하여 다양한 지형에서도 정확히 착지
단순 직선 이동 → 포물선 궤적 + 회전 애니메이션으로 시각적 생동감 강화
GameplayCue 연동으로 착지 시 사운드·이펙트 확장 용이한 구조 확보
UI 이중 프로그레스 바
앞면 바는 속성값 즉시 반영, 뒷면 바는 FMath::FInterpTo로 부드럽게 따라오도록 구현
NativeTick에서 지속 갱신, FMath::IsNearlyEqual로 값 차이가 작아지면 보간 종료하여 성능 최적화
급격한 속성 소모 시 뒷면 바도 즉시 갱신하여 실시간 피드백 유지
스크린 공간 UI 시야 차단
스크린 공간 UI로 거리별 해상도 유지
NativeTick에서 LineTrace로 카메라와 대상 간 장애물 감지, 가려진 경우 UI 비활성화
일정 거리 이상 멀어지면 UI 자동 숨김으로 불필요한 렌더링 방지
향상된 락온 시스템
반경 내 모든 적을 탐색하여 카메라 기준 가장 정면에 가까운 적을 내적 계산으로 우선순위 결정
카메라 오른쪽 벡터 기준으로 좌우 입력에 따라 타겟 전환 기능 추가
타겟 사망, 거리 이탈 시 자동 해제 / 수동 해제 입력 지원
