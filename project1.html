진행 기간 2026 · 개발 중
개발 인원 프로그래머 1명
사용 기술 C++, Unreal Engine, Dedicated Server, Docker, nginx, MariaDB, Amazon Web Services
담당 파트 데디케이티드 서버 구축 및 AWS 인프라 연동
서버 권한 기반 게임플레이 시스템 구현
인증 서버 설계 및 3티어 컨테이너 아키텍처 구축
언리얼 데디케이티드 서버 구축 DONE
Windows → Linux 크로스 컴파일로 데디케이티드 서버 빌드 및 패키징
UnrealBuildTool(LinuxToolChain.cs) 직접 수정으로 크로스 컴파일 파이프라인 문제 해결
AWS EC2(Ubuntu)에 배포, 클라이언트-서버 접속 및 리플리케이션 정상 동작 확인
서버 권한(HasAuthority) 기반 콤보 공격 시스템 구현
인증 서버 DONE
C++(cpp-httplib) 기반 회원가입/로그인/토큰 검증 REST API 직접 구현
PBKDF2-HMAC-SHA256 비밀번호 해싱, JWT 발급·검증(jwt-cpp) 적용
nginx → Auth Server → MariaDB 3티어 아키텍처로 Docker Compose 컨테이너화
회원가입 → 로그인 → 토큰 검증 전체 흐름 및 DB 저장 데이터 검증 완료
