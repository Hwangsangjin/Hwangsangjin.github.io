Eternal Quest: Blueprint

게임 제목 Eternal Quest: Blueprint
게임 소개 언리얼 블루프린트 비주얼 스크립팅을 활용한 액션 RPG
진행 기간 2025.03.20 ~ 2025.03.26
개발 인원 프로그래머 1명
사용 기술 Unreal Engine, Blueprint
담당 파트 블루프린트 기반 플레이어 캐릭터 및 AI 구현
게임 UI 및 인터랙션 시스템 구현
타겟 락온
SphereTrace로 카메라 전방 범위 내 적 탐지, 충돌 채널 필터링으로 적 캐릭터만 감지
탐지된 적 중 카메라 시야 중심과 가장 가까운 적 자동 선택
좌우 입력으로 타겟 전환 기능 추가
타겟 사망, 거리 이탈 시 자동 해제 / 수동 해제 입력 지원
스트레이핑 애니메이션
캐릭터 XY 평면 속도를 추출하여 블렌드 스페이스의 속도 입력으로 사용
캐릭터 회전 방향과 속도 벡터의 차이로 상대 이동 각도 산출, 블렌드 스페이스 방향 입력에 연동
전방·후진·좌우·대각선 모든 방향 자연스럽게 표현
SDF 텍스처 얼굴 그림자
SDF 텍스처 픽셀별 가장자리 거리 정보를 활용하여 경계 부근 부드러운 페이드 효과 적용
머티리얼 셰이더에서 SDF 값 샘플링 후 smoothstep으로 알파 값 점진적 감소
경계에서 자연스럽게 사라지는 부드러운 윤곽 그림자 구현
미니맵
씬 캡처 컴포넌트의 ShowOnlyActors / HiddenActors로 미니맵 전용 렌더링 설정 구성
건물 외벽·지붕은 미니맵 렌더링에서 제외, 실제 게임 화면에는 유지
건물 내부 진입 시에도 미니맵이 올바르게 표시되도록 개선
