KEY IMPLEMENTATIONS

  • 서버 계층 분리 — Nginx 리버스 프록시로 WAS IP 은닉, DB는 WAS 전용 계정으로 접근 제한
  • proxy_pass 404 오류 해결 — try_files와 proxy_pass 역할 충돌 원인 분석 및 설정 분리로 해결
  • 실제 클라이언트 IP 로깅 — X-Forwarded-For 헤더를 Tomcat 로그 패턴에 적용
  • MariaDB 외부 접속 제어 — bind-address 설정 변경 및 WAS 전용 계정 생성으로 DB 보안 강화
  • 포워드 프록시 검증 — tinyproxy로 리버스/포워드 프록시 동작 차이 비교
  • SQL 인젝션 대응 — Statement → PreparedStatement 교체로 인증 우회 차단
