TEAM PROJECT · 2024

Eternal Quest: Origin

게임 제목 Eternal Quest: Origin
게임 소개 언리얼 온라인 서브시스템을 활용한 온라인 RPG
진행 기간 2024.02.05 ~ 2024.03.13
개발 인원 프로그래머 3명
사용 기술 Unreal Engine, Online Subsystem, Steamworks SDK, Git
담당 파트 멀티플레이어 네트워크 환경 구축 및 Steam 플랫폼 연동
직업별 이동·공격·스킬 컴포넌트 제작 및 네트워크 동기화
멀티플레이어 네트워크 통합
Online Subsystem + Steamworks SDK 연동
세션 생성·검색·참가·종료 전 과정을 API로 직접 제어
서로 다른 네트워크 환경에서도 안정적인 매칭과 세션 참여 가능하도록 설계
발행-구독 기반 게임 세션 관리
언리얼 델리게이트 시스템으로 발행-구독 패턴 적용
세션 이벤트를 델리게이트로 발행, 객체 간 직접 참조 제거
시스템 간 결합도 감소 및 이벤트 관리 유연화
캐릭터 직업 정보 동기화
클라이언트 직업 선택 정보를 Server RPC로 전송
서버에서 NetMulticast RPC로 모든 클라이언트에 동기화
서버 권한 검증으로 클라이언트의 직접 수정 차단
동기화된 직업 정보 기반 비동기 에셋 로딩으로 시각적 일관성 확보
비동기 에셋 로딩
초기 일괄 로드 방식에서 LoadAssetAsync 기반 필요 시점 로딩으로 전환
약한 참조 경로만 관리하여 불필요한 메모리 점유 방지
초기 로딩 시간 단축 및 메모리 효율 개선
