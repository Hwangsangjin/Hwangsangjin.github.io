개인 프로젝트 2025

Eternal Quest: Blueprint

언리얼 블루프린트 비주얼 스크립팅으로 타겟 락온, 스트레이핑 애니메이션, 행동 트리 AI, SDF 얼굴 그림자와 미니맵을 구현한 액션 RPG입니다.

게임 소개
언리얼 블루프린트 비주얼 스크립팅을 활용한 액션 RPG
진행 기간
2025.03.20 ~ 2025.03.26
개발 인원
프로그래머 1명
사용 기술
Unreal Engine, Blueprint
담당 파트
블루프린트 기반 플레이어 캐릭터 및 AI 구현
게임 UI 및 인터랙션 시스템 구현

주요 구현

타겟 락온

  • 카메라 중심선을 따라 SphereTrace를 쏴 먼저 걸린 적을 대상으로 지정, 충돌 채널로 적 캐릭터만 감지
  • 락온 시 마커 위젯 액터를 대상에 부착하고, FindLookAtRotation으로 컨트롤러가 대상을 계속 바라보게 유지
  • 락온 중에는 캐릭터가 이동 방향 대신 컨트롤러 방향을 따르도록 회전 방식을 전환해 스트레이핑과 연결
  • 대상이 유효 거리를 벗어나거나 수동 해제 입력 시 마커를 제거하고 락온 해제

전투 입력과 방향별 회피

  • 공격·회피·가드·포션·락온 입력을 전투 컴포넌트에서 Enhanced Input으로 처리
  • 연속 입력 시 다음 콤보로 이어지는 연속 공격과 가드 상태 관리
  • 입력 방향을 전·후·좌·우로 판별해 방향별 구르기 몽타주 재생, 스태미나 소모 후 타이머로 자동 회복
  • 질주 입력 시 스탯 컴포넌트의 이동 속도 값을 기준으로 타임라인을 통해 최대 속도를 부드럽게 전환

스트레이핑 애니메이션

  • 이동 속도만으로 애니메이션을 전환하던 초기 방식은 좌우·대각선 이동 시 방향과 동작이 어긋남
  • XY 평면 속도와 CalculateDirection으로 구한 이동 방향을 블렌드 스페이스의 속도·방향 입력으로 연동
  • 락온 중 전후·좌우·대각선 모든 방향에서 실제 이동 방향과 애니메이션 일치

행동 트리 기반 적 AI

  • PawnSensing으로 플레이어를 발견하면 블랙보드에 타겟과 발견 여부를 기록
  • 발견 여부 데코레이터로 "추적 → 검 공격" 시퀀스와 대기 시퀀스를 분기, AI MoveTo로 추적
  • 공격 태스크는 적 인터페이스에서 몽타주와 재생 속도를 받아 재생하고, 몽타주가 끝나면 태스크 완료
  • 적은 두 가지 공격 몽타주 중 하나를 무작위로 골라 공격 패턴에 변화를 줌

설계와 문제 해결

컴포넌트·인터페이스 기반 구조

  • 캐릭터 기능을 전투 컴포넌트와 스탯 컴포넌트로 분리해, 입력·판정과 체력·스태미나 관리를 나눔
  • 캐릭터 상태(이동·공격·사망)와 스탯 종류(체력·스태미나)를 Enum으로 정의해 상태 전환과 스탯 증감 기준으로 사용
  • 공격 판정 시작·종료, 사망, 적 공격 정보를 각각 블루프린트 인터페이스로 정의해 플레이어와 적이 같은 방식으로 호출

애님 블루프린트 상태 머신과 노티파이 이벤트

  • 상태 머신은 이동 애니메이션을, 공격·가드·사망 슬롯은 몽타주를 맡도록 분리해 블렌딩
  • 콤보 확인·공격 전진·범위 공격·공격 종료 시점을 애님 노티파이 이벤트로 받아 캐릭터 로직과 연결
  • 미러 데이터 테이블로 애니메이션을 좌우 반전해 재사용

애니메이션 노티파이 기반 공격 판정

  • 공격 몽타주에 노티파이 스테이트를 두고, 구간 시작·종료 시 인터페이스로 소유자의 판정 시작·종료 호출
  • 판정 구간 동안 타이머로 무기 소켓 위치를 따라 SphereTrace를 반복해 적중한 대상에 데미지 적용
  • 같은 노티파이 스테이트를 플레이어와 적의 공격 몽타주에 모두 적용해 공격 판정 로직을 공유

피격과 사망 처리

  • 데미지를 받으면 체력을 줄이고 피격 몽타주를 재생하며, 타임라인으로 머티리얼 파라미터를 바꿔 피격 효과 표시
  • 체력이 0이 되면 사망 몽타주를 재생하고, 사망 인터페이스와 이벤트로 사망을 알림
  • 적도 같은 데미지 흐름으로 체력 바 갱신, 피격 몽타주, 사망 처리를 수행

데이터 에셋과 상속 기반 장비·아이템

  • 무기 이름·아이콘·메시·데미지·부착 소켓을 PrimaryDataAsset으로 분리해, 새 무기는 데이터만 만들어 교체
  • 부모 블루프린트(무기·방패·포션)에 공통 로직을 두고, 자식에서 무기 3종·방패·체력/마나 포션으로 확장
  • 포션 사용 시 손 소켓에 포션을 붙이고 마시는 몽타주를 재생, 사용 중 여부는 상태 플래그로 관리

무기 획득 인터랙션

  • 월드에 놓인 무기에 오버레이 머티리얼로 외곽선을 표시해 획득 가능한 대상임을 구분
  • 캐릭터가 겹치면 무기가 이벤트 디스패처로 획득을 알리고, 캐릭터가 이를 받아 지정 소켓에 무기를 부착
  • 무기가 캐릭터를 직접 제어하지 않아, 새 무기도 같은 획득 흐름을 그대로 사용

HUD와 적 체력 UI

  • 플레이어 HUD에 체력·스태미나 바와 스킬 슬롯을 배치하고, 스탯 컴포넌트가 최대값 대비 현재값 비율로 진행 바 갱신
  • 적은 보스 여부에 따라 보스 전용 체력 바 또는 머리 위 위젯 컴포넌트로 체력을 표시
  • 머리 위 위젯은 빌보드 컴포넌트로 매 틱 카메라 방향을 향하도록 회전

얼굴 그림자의 계단 현상 개선

  • 기존 셰이딩에서는 얼굴·머리 윤곽 주변에 계단 현상이 생기고 복잡한 경계에서 그림자가 뭉개짐
  • 픽셀마다 가장자리까지의 거리를 담은 SDF 텍스처를 샘플링하고, smoothstep으로 특정 거리 구간에서 알파를 점진적으로 감소
  • 경계에서 그림자가 자연스럽게 사라져 얼굴 윤곽을 따라 부드럽게 표현

건물 내부 미니맵 가림 해결

  • 캐릭터에 부착한 씬 캡처가 렌더 타겟에 위에서 내려다본 화면을 그리고, 미니맵 위젯이 이를 표시
  • 플레이어가 건물 안에 들어가면 벽과 지붕이 씬 캡처 시야를 가려 내부가 보이지 않는 문제 발생
  • 씬 캡처의 HiddenActors로 건물 외벽·지붕을 미니맵 렌더링에서만 제외해, 게임 화면의 건물은 유지
