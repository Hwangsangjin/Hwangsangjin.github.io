개인 프로젝트 2025

Eternal Quest: Rebirth

언리얼 게임플레이 어빌리티 시스템으로 전투, 패링·방어, 락온, UI를 설계하고, 블루프린트로 구현한 프로토타입을 C++ 기반으로 확장한 액션 RPG입니다.

게임 소개
언리얼 게임플레이 어빌리티 시스템을 활용한 액션 RPG
진행 기간
2025.05.26 ~ 2025.06.26
개발 인원
프로그래머 1명
사용 기술
C++, Unreal Engine, Gameplay Ability System, Gameplay Tag
담당 파트
게임플레이 어빌리티 시스템 기반 전투 구현
게임 UI 및 인터랙션 시스템 구현

주요 구현

GAS 기반 전투 어빌리티

  • 공격·구르기·질주·점프·상호작용·전투 전환을 GameplayAbility로 구현하고, 입력 ID로 매핑해 입력 처리와 능력 로직 분리
  • 체력·마나·스태미나와 공격 범위·반경·속도를 AttributeSet으로 관리
  • 데미지는 GameplayEffect, 타격·아이템 연출은 GameplayCue로 처리해 수치 계산과 연출 분리

픽업 아이템 스폰

  • 캐릭터 정면 기준 45도 범위에서 방향과 거리를 무작위로 정해, 매번 다른 곳으로 튕겨 나가도록 구현
  • 목표 지점 위에서 아래로 LineTrace를 쏴 지면 높이를 구하고, 지면을 찾지 못하면 시작 높이로 대체
  • 포물선 궤적과 회전 애니메이션으로 시각적 생동감 강화
  • 착지 시 GameplayCue를 실행해 사운드·이펙트를 코드 수정 없이 추가 가능

UI 이중 프로그레스 바

  • 앞면 바는 속성값 즉시 반영, 뒷면 바는 0.5초 지연 후 FMath::FInterpTo로 따라오도록 구현
  • NativeTick에서 갱신하고, FMath::IsNearlyEqual로 값 차이가 충분히 작아지면 보간 종료
  • 질주 중에는 뒷면 바도 즉시 갱신해 연속 소모 상황에서 피드백 지연 방지
  • 무적 태그 변화 이벤트를 구독해, 구르기 무적 동안 바 색상을 바꿔 상태를 표시

스크린 공간 UI 시야 차단

  • 월드 공간 UI의 거리별 해상도 저하를 피해 스크린 공간 UI로 체력 바 표시
  • NPC의 Tick에서 30m 밖이면 트레이스 없이 숨기고, 30m 이내일 때만 카메라와 대상 사이를 LineTrace로 검사
  • 장애물에 가려지면 숨기되, 가시성 상태가 바뀔 때만 갱신해 불필요한 호출 방지

설계와 문제 해결

GAS 기반 전투 구조

  • AbilitySystemComponent와 AttributeSet을 PlayerState에 두고 캐릭터를 아바타로 연결해, 폰이 바뀌어도 속성과 어빌리티 유지
  • 하나의 입력에 홀드 조건을 걸어, 짧게 누르면 구르기, 길게 누르면 질주 어빌리티로 분기
  • 공격·구르기·무적·패링 등 캐릭터 상태를 네이티브 Gameplay Tag로 정의해 어빌리티 활성 조건과 상태 전환 판단

무기 데이터 기반 전투 모드 전환

  • 무기별 몽타주 데이터 에셋에 공격·장착·해제·패링 등 행동 태그와 몽타주를 연결해, 무기마다 다른 동작 지정
  • 전투 전환 어빌리티가 장착·해제 몽타주를 재생하고, AnimNotify 시점에 무기와 방패를 장착 소켓과 보관 소켓 사이로 이동
  • 전환 진행 태그와 쿨다운 태그로 연속 입력으로 인한 중복 전환 방지

데미지와 스태미나 처리

  • 데미지를 메타 속성으로 받아 PostGameplayEffectExecute에서 체력에 반영하고, 무적 태그가 있으면 적용 전에 무효화
  • 질주 중에는 스태미나 소모 이펙트를 지속 적용하고 회복을 멈추며, 0이 되면 질주를 자동 취소
  • 체력이 0이 되면 사망 태그를 부여하고 델리게이트로 발행해 후속 처리와 연결

애니메이션 이벤트 기반 타격 판정

  • 공격 몽타주의 AnimNotify가 콤보 단계를 담은 Gameplay Event를 보내 판정 어빌리티를 활성화
  • 커스텀 AbilityTask와 TargetActor로 트레이스 결과를 받아, 상대의 막기 가능 여부에 따라 방어·피격 상태로 분기
  • 콤보 단계별 데미지를 SetByCaller로 GameplayEffect에 전달하고, 타격 지점을 담은 GameplayCue로 이펙트 재생

패링·방어 판정

  • 검·방패 무기를 들고 있고 공격·구르기·피격·사망 상태가 아닐 때만 패링 허용
  • 피격 시 공격자 방향과의 내적으로 정면 여부를 판단해, 정면에서 받은 공격만 방어·패링 성공으로 처리
  • 방어에 성공하면 데미지 없이 방패 이펙트를, 실패하면 피격 이펙트와 사운드를 재생해 결과를 구분
  • 방어에 실패하면 공격자 방향을 계산해 그 방향에 맞는 피격 몽타주를 선택

락온 시스템 재설계

  • 블루프린트 프로토타입은 SphereTrace에 먼저 걸린 적을 선택해, 카메라 각도에 따라 의도치 않은 적이 잡히고 좌우 전환이 없었음
  • 반경 내 후보 중 LineTrace로 가려진 대상을 제외하고, 카메라 정면 벡터와의 내적이 가장 큰 적을 선택
  • 오른쪽 벡터와의 내적 부호로 좌우 전환하고, 전환 대상이 없으면 기존 타겟 유지, 사망하거나 20m를 벗어나면 자동 해제

인터페이스 기반 대상 분리

  • 상호작용·전투·락온 대상을 각각 인터페이스로 정의해, 어빌리티와 컴포넌트가 구체 클래스 대신 인터페이스로 대상과 통신
  • 상호작용 어빌리티는 공격 판정과 같은 커스텀 AbilityTask를 재사용하고 TargetActor만 바꿔, 감지한 대상의 상호작용 함수를 호출
  • 새로운 상호작용·전투 대상도 인터페이스만 구현하면 기존 어빌리티 수정 없이 추가 가능

행동 트리 기반 적 AI

  • AIPerception으로 감지한 대상을 블랙보드 타겟으로 두고, 서비스 노드가 거리를 주기적으로 확인해 근접 공격·접근·순찰·대기 중 행동 선택
  • 확률·거리 조건 데코레이터와 순찰 지점 탐색·이동 속도 변경 태스크를 C++ 노드로 구현해 행동 트리에서 조합
  • 공격 태스크는 전투 인터페이스에 공격 태그만 넘기고, 몽타주 종료 콜백에서 완료해 공격 도중 다음 행동으로 넘어가지 않도록 처리
